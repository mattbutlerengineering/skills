# Launch: A knowledge base that knows when its outside facts go stale

## What it is

This update teaches a project's knowledge base about the things it could not see before. A note about something outside the code can now say what it was checked against, when, and for how long that check holds. The step that gathers new note ideas now also looks at what people told the agent and at what the agent saved in its own memory.

## What it does

A note about an outside system now carries the date it was last checked and how long that check stays good. Once that time runs out, the routine check names the note and asks for a re-check, without going online. The gathering step lists the moments a person corrected the agent or answered its question, and it pairs saved memories with the notes that already cover them.

## How it helps

Facts about the world outside the code stop being trusted forever just because nobody looked again. Lessons that lived only in one person's private memory get a path into the shared notes, where every session and every scheduled job can read them. A person still decides what becomes a note.
