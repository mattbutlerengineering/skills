# Claims: documentation audit

The one record of this run's audit of the thirteen living docs (PRD-0010),
laid out as `architecture.md` § Data model fixes. A supporting file, not a
protocol artifact: no stage owns it and the router never reads it. Implement
writes it doc by doc; Verify appends the last section.

## Preamble

- **Base audited.** `feat/grok-harness` at
  `a0f7553905e93f97db571412ab35f8c88bfe8778` (`git rev-parse
  feat/grok-harness`, 2026-10-10). Every **Line** cell is the line number in
  the doc as it read at that commit; scope diffs are
  `git diff feat/grok-harness...HEAD`.
- **Verdicts.** `true` — the tree bears the claim out. `false` — the tree
  says otherwise. `stale` — PRD-0010's operational definition: the passage
  describes something the tree no longer has or no longer does (a removed
  file, a renamed module or checker, a retired command, a superseded ADR
  presented as standing, a roster or count that no longer matches).
- **Checkable claim.** One the tree can falsify: a path, a command or flag,
  a module, function or checker name, a count, an ADR status, a skill
  roster. **Kind** is one of `path`, `command`, `name`, `count`,
  `adr-status`, `roster`. Claims about remote state — a cloud trigger id, a
  GitHub issue's open/closed state, a label as it exists on GitHub — are
  not tree claims and are not inventoried (architecture decision (g)).
- **Check contract.** Each **Check** is one backticked shell command, run
  from the repo root in zsh with only the repo and the Python 3 standard
  library, read-only and idempotent, that exits 0 if and only if the claim
  as written holds. No `gh`, no network, and `trigger_eval.py` /
  `charter_replay.py` are never run — their flags are checked by grepping
  their argument parsers. No Check cell contains a `|` character, so the
  column can be extracted verbatim. Where a command cannot express the
  claim, the Check is a `grep -n` of the bearing line and the verdict says
  the auditor read it. **Result** is the exit code and the last non-empty
  output line (backticks shown as `'`, `|` escaped, and a Markdown link's
  `](` broken to `] (` so detector I never reads a quoted line as a link).
- **Dispositions.** Blank for `true`. For `false`/`stale`, exactly one of
  `corrected → <new text>; check <command>` (the new Check exits 0 on the
  edited tree; the original Check is what proved the old text false),
  `removed`, or `follow-up F-n` (a row in Follow-ups).
- **Beads blocks.** Text between the `BEGIN BEADS` and `END BEADS` markers
  of `CLAUDE.md` and `AGENTS.md` is generated by `bd setup` and is never
  edited here; a false line inside one is a follow-up naming `bd setup` as
  its owner.
- **Row-id prefixes.** README, CONTEXT, LEDGER, CLAUDE, AGENTS, SETUP, PROTO,
  OEVAL (`docs/output-evals.md`), ROUT-GARD, ROUT-IMPR, ROUT-GROOM,
  ROUT-RETRO (the four routine playbooks), EVALS (`evals/README.md`);
  follow-ups are F-1, F-2, and so on. Ids never renumber.

## Link scan

The command (reuses `gates.MD_LINK` and `gates.URL_TARGET`; same skip and
resolution rules as detector I's `check_staleness`; exactly the thirteen
files):

```sh
python3 -c "import gates, pathlib, sys; r = pathlib.Path('.').resolve(); fs = 'README.md CONTEXT.md LEDGER.md AGENTS.md CLAUDE.md docs/setup.md docs/pipeline-protocol.md docs/output-evals.md docs/factory/doc-gardener-routine.md docs/factory/improvement-routine.md docs/factory/queue-groomer-routine.md docs/factory/retro-reflect-routine.md evals/README.md'.split(); links = [(f, n, t.split('#', 1)[0]) for f in fs for n, line in enumerate((r / f).read_text(encoding='utf-8').splitlines(), 1) for t in gates.MD_LINK.findall(line) if not (gates.URL_TARGET.match(t) or t.startswith('#'))]; links = [x for x in links if x[2]]; missing = [x for x in links if not ((r if x[2].startswith('/') else (r / x[0]).parent) / x[2].lstrip('/')).exists()]; [print(f'missing: {f}:{n} {t}') for f, n, t in missing]; print(f'links: {len(links)} relative across {len(fs)} files, {len(missing)} missing'); sys.exit(1 if missing else 0)"
```
